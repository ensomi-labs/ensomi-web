R2 のデータはどこから来たか

ensomi R2 がどの譜面と音楽から、何のために作られたか。監査でわかることとわからないこと、私たちが決めたこと、そして訂正を依頼する方法をまとめます。

  • 監査の証拠：2026-10-17 時点のスナップショット
  • 方針の声明：2026-10-21

このページは翻訳です。正式な内容は英語版です。

このページが対象とするのは ensomi R2 1.0 と 1.0.1、つまりモデルカードのリリース r2-1.0 と r2-1.0.1 だけで、R1 などそれ以前のモデルは含みません。内容は、詳しい資料であるデータの出所に関する報告書（英語、変更履歴）を要約したものです。

R2 が使ったもの、その目的

R2 は、osu! の Ranked と Loved の osu!mania 4K 譜面（★2〜6）から作られました。これらの譜面と音声は、モデルと一緒には配布していません。以下の各部分がどう組み合わさるかは R2 レポート（英語）にあります。

  • 学習。学習対象の 11,368 譜面で、二つのモデルを学習しました。行モデルは、音楽の特徴量と、マッパー自身のタイミングとノーツの始まる位置から、ノーツがどこで始まるかを学びます。R2 は譜面の行から、ノーツの配置の仕方を学びます。R2 は音声を聴いていません。どちらも、以前のモデルの重みを使わず、ゼロから学習しました。
  • コーパス事前分布（corpus prior）。新しい譜面のキャラクター（たとえばロングノーツの多さ）を、ノーツの置かれ方が似ている学習用譜面から取ります。公開している prior.json には、学習用譜面 1 つにつき 1 行の数値が、名前なしで入っています。名前がなくても、もとの譜面に由来することに変わりはありません。
  • キャリブレーション。モデルと一緒に公開している、プレイアビリティ（遊べること）のためのキャリブレーションとスコープ表には、学習用譜面から導いた数値が入っています。
  • タイミング。マッパーのテンポ、ビートグリッド、ノーツの位置を基準にして、R2 が曲の音声にビートグリッドを合わせる方法を選びました。決めたのは手法の選択で、追加のニューラルモデルは学習していません。
  • 評価と試聴。一部の譜面は、生成した譜面を測る評価パネルや、聴き比べの参照として選ばれました。
  • プレビュー。モデルと一緒に公開している 4 つのプレビューは、元になった 4 曲の音声を使っています。元譜面のマッパーは報告書に記載していますが、生成された配置の作者ではありません。
  • ビート検出。R2 は、作者たち自身が事前学習したビート検出器 BeatThis の final0 を、追加学習せずにそのまま使います。その学習データは作者たち自身が用意したもので、そのデータに含まれる音楽家の記録は不完全です。

数字と、それが意味しないこと

以下は、2026-10-17 時点で監査が確認した、学習対象の 11,368 譜面についての数です。ラベルは譜面のメタデータにある記載で、確認された人物や権利者ではありません。

11,368 譜面
譜面とは一つの難易度、つまり重複のない一つの .osu ファイルです。
Creator ラベル 1,129 件
譜面に書かれたマッパー名の種類数です。別名はまとめず、合作の表記も分けていません。ゲスト難易度の作者が抜けていることもあります。
Artist ラベル 2,445 件
譜面に書かれたアーティスト名の種類数です。作曲者、演奏者、権利者の一覧ではありません。「Various Artists」も一つのラベルです。
音声ハッシュ 5,026 件
ファイルの正確なバイト列について記録されたハッシュで区別した、音声ファイルの数です。曲の数ではありません。同じ曲でも別のファイルなら別に数えます。
グループ 4,167 件
関連する元データを同じデータ区分にまとめておくためのグループです。これも曲の数ではありません。

学習対象とは、学習が譜面を抜き出すもとになった集合に入っていたという意味です。記録からは、ある譜面が抜き出されたかどうか、何回抜き出されたか、モデルに何をもたらしたかはわかりません。監査の出発点である凍結済みの全目録には 22,066 譜面がありますが、これは学習に使った集合ではありません。

監査でわかること、わからないこと

監査では、記録された R2 の段階それぞれが、どの譜面と、どの Creator ラベル・Artist ラベルを使ったかを確かめました。学習とキャリブレーションから、評価とプレビューまでを含みます。各段階の記録は譜面ファイルの正確なハッシュで譜面と結びつけてあり、すべての記録が一致しました。

次のことは未解決です。

  • 権利処理。監査は、譜面や音楽を使う許可を確認するものではありません。
  • 譜面と音楽の入手経緯と、許諾についての完全な調査。
  • ラベルの背後にいるマッパーや音楽家が誰なのか。
  • 学習が実際にどの譜面を何回抜き出したか。
  • BeatThis の学習データに含まれる音楽家の完全な一覧。

私たちが決めたこと

方針の声明：2026-10-21

公開済みのモデル r2-1.0 と r2-1.0.1 は、このデータの出所の開示とともに、引き続き公開します。

今後公開するモデルには、意図する学習と公開の用途に適した、寛容なライセンスまたは明示的な許可のあるデータを使います。そうしたリリースのデータの確認では、学習用の譜面だけでなく、該当する場合は、引き継いだ重み、事前学習済みのビート検出器のような上流のコンポーネント、以前のモデルからの蒸留、事前分布やキャリブレーション表のような派生データも対象にします。

この方針は監査とは別のものです。監査は、R2 のもとになったデータがこの方針を満たすことを示していません。

参加登録とオプトアウト

貢献者の参加登録（オプトイン）とオプトアウトの依頼について検討しています。その決定が、該当する譜面や音楽の権利者からのものだと手軽に確かめる方法も検討に含みます。こうした仕組みはまだ整っておらず、既存のモデルにどう影響するかも決まっていません。公開済みのモデルが、ある元データからすでに学んだことを取り除けるとは主張していません。

表で確かめる

stage_counts.csv には、段階ごとの譜面、グループ、音声ハッシュ、ラベルの数があり、各列の説明は表の README（英語）にあります。二つのラベル表 creator_labels_by_stage.csv と artist_labels_by_stage.csv は、段階ごとに Creator と Artist のラベルを記載どおりにすべて載せるものですが、まだ公開していません。

公開後に名前を探すには、stage を絞り込み（たとえば学習用の 11,368 譜面なら r2_cache_fit_train）、raw_label を検索してください。別名はまとめず、合作の表記も分けていないので、名前の一部でも検索してください。開発用の集合、評価パネル、プレビューなど、ほかの段階にはそれぞれの ID があります。段階どうしは重なっているので、数を足し合わせないでください。

訂正と質問

帰属表示の訂正、譜面や曲の使われ方についての質問、参加登録やオプトアウトへの関心は、GitHub のデータの出所に関する issue でお知らせください。英語、日本語、中国語のどれでもかまいません。

データの出所の issue を開く

issue は公開されます。個人情報や音声は含めないでください。ビートマップのリンクか ID、または表に載っているとおりのラベルがあれば十分です。issue を開いただけで、公開済みのモデルから何かが取り除かれることはありません。
