R2 的数据从何而来

R2 用了哪些谱面和音乐、用来做什么，我们的审计能说明什么，我们做了什么决定，以及如何申请更正。

  • 最后更新 2026-10-21
  • 审计证据：2026-10-17 的快照
  • 政策声明：2026-10-21

本页为译文，内容以英文版为准。

本页只涉及 ensomi R2 1.0 和 1.0.1，不涉及 R1 或其他更早的模型。本页是我们的数据来源报告（英文）的摘要，详细内容见报告，不作超出报告的声明。

R2 用了什么，用来做什么

R2 基于 osu! 上 2 到 6 星的 Ranked 与 Loved 4K 谱面构建。我们不分发这些谱面及其音频。

  • 训练。11,368 张符合训练条件的谱面训练了行模型和 R2：行模型根据音乐和谱师的时间轴学习音符从哪里开始，R2 则在听不到音频的情况下编排音符。
  • 语料先验。它从相似的训练谱面中为新谱面取得风格。随模型发布的 prior.json 为每张训练谱面保留一行数字，不含名字。
  • 校准。随模型发布的可玩性校准和 scope 表由训练谱面得出。
  • 时间轴。谱师的速度、节拍网格和音符被用作参照，用来选定 R2 如何把节拍网格对齐到音频。
  • 评估。部分谱面被用作衡量和试听生成谱面时的参照。
  • 预览。随模型发布的四个预览使用了四首源歌曲的音频。报告列出的源谱面谱师不是生成谱面的作者。
  • 节拍检测。R2 原样使用其作者训练好的 BeatThis final0；它的训练数据中的音乐人没有完整记录。

R2 并非为模仿某位特定谱师或艺术家而构建：它的模型不接收谱师或艺术家的名字或 ID，以全部训练谱面为一个整体从零开始训练，训练抽样、微调、可玩性限制和评估指标都没有按谱师或艺术家分别设定（依据与局限，英文）。

这些数字，以及它们不代表什么

以下是 2026-10-17 时符合训练条件的谱面的统计。标签是谱面元数据中的声明，不是经过核实的人或权利人。

11,368 张谱面
一张谱面就是一个难度，即一个 .osu 文件。
1,129 个 Creator 标签
谱面中写明的谱师名。别名没有合并，合作署名没有拆分，客串难度的作者可能缺失。
2,445 个 Artist 标签
谱面中写明的艺术家名，不是作曲者、演奏者或权利人的名单。
5,026 个音频哈希
按确切字节区分的音频文件，不是歌曲数。
4,167 个分组
用来把相关来源保持在同一数据划分中的分组，不是歌曲数。

“符合训练条件”是指谱面属于训练从中抽取的那一池谱面；某张谱面是否被抽到、被抽到几次，并没有记录。审计起点的完整冻结清单共有 22,066 张谱面，它不是训练所用的集合。

审计能说明什么，不能说明什么

审计确定的是署名与阶段归属：R2 每个有记录的阶段用了哪些谱面和标签。它不是权利清理，也不是对获取途径和许可的完整审查。标签背后究竟是谁、训练实际抽到了哪些谱面、BeatThis 训练数据中音乐人的完整名单，仍未解决。

我们的决定

政策声明：2026-10-21

已发布的模型 r2-1.0 和 r2-1.0.1 将继续提供，并附上这份说明。今后发布的模型将使用采用宽松许可、或获得明确许可的数据，且许可须适合预期的训练和发布用途；其数据审查会视情况涵盖继承的权重、上游组件、蒸馏和派生数据。审计并不能说明 R2 的数据满足这一政策。

加入与退出

我们正在探索加入（opt-in）和退出（opt-out），包括一种方便的方式，用来核实某个决定确实出自权利人。目前还没有这样的流程，我们也不声称能从已发布的模型中去除它已经学到的东西。

在表格中查询

stage_counts.csv 列出每个阶段的数量，它的 README（英文）加以说明。列出全部 Creator 和 Artist 标签的表格尚未发布；发布后，请按 stage 筛选（训练谱面为 r2_cache_fit_train），再搜索 raw_label，也可以只搜名字的一部分。各阶段相互重叠，请不要把它们的数量相加。

更正与提问

如需更正署名、询问某张谱面或某首歌如何被使用，或表示对加入与退出感兴趣，请在 GitHub 上提交 issue。英文、日文和中文都可以。

提交数据来源 issue

issue 是公开的：请不要附上个人信息或音频。提交 issue 本身不会从已发布的模型中移除任何内容。
