R2 · 首个公开可玩的版本

ensomi — Play the music around you.

えんそみ — 聴く音楽から、参加する音楽へ。

选一首你喜欢的歌，R2 就在你的浏览器里为它写谱。先看着谱面跟着音乐滚动，再导入 osu! 亲自玩。歌曲不会离开你的电脑。

谱面生成器需要在电脑浏览器中使用。请在电脑上打开此页面，加载模型、选择歌曲并生成谱面。

我们为什么做 ensomi

大多数时候，音乐是用来听的。音乐游戏让你走进一首歌：双手跟着节拍，聆听变成了演奏。可一首歌要等有人一个音符一个音符地手工写好谱，才能玩；而你生活中的大多数音乐，永远等不到一张谱面。

我们想改变这一点。ensomi 从谱师写的谱面中学习，再根据音频写出新的谱面，让你喜欢的音乐、身边正在播放的音乐，都能变成可以玩的东西。

我们在做什么

我们希望听音乐、玩音乐和为音乐写谱成为同一件事。下面四个场景说明了我们的意思。

随处可玩

身边的音乐，变成你可以玩的东西。

附近已经在放一首歌。ensomi 识别出它、找到播放位置，然后开始一张实时生成的谱面，跟着音乐走，不打断音乐。

写谱

配置由你决定，ensomi 提供候选。

谱师选中一段，请 ensomi 给出配置候选，谱面其余部分保持不动。比较、保留、重试或撤销，选择和表达都留在谱师手中。

练习

用喜欢的音乐练习。

玩家选择喜欢的歌和想提高的动作，谱面就围绕这个动作来生成。

一起玩

你打得好，对手的谱面就会变难。

就像对战俄罗斯方块里消行一样，打得干净的一段或长连击会发出攻击：一串音符或更难的键型，掉进对手接下来要打的谱面里。合作模式下则要互相配合，一个人的演奏会塑造另一个人的谱面。

我们还没走到那一步。每个场景都需要这样的谱面：在你要求的难度下可以玩、贴合音乐、整首歌保持统一的风格，并回应你的要求。R2 是我们的第一步：稍等片刻就能得到整首歌的谱面，而且已经可以为其中一段指定风格。它还不能实时跟着音乐生成、不能在有人游玩时改变谱面，也不能重写现有谱面的某一段。

R2：从一首歌到一张能玩的谱面

R2 是我们首个公开可玩的版本。它只依靠音频工作，从你的歌到你的谱面，中间经过三步。

  1. 找到节拍。R2 先听出节拍，再把每个速度段对齐到歌曲中声音开始的位置。
  2. 决定音符落在哪里。根据听到的声音，一拍一拍地决定音符从哪里开始。
  3. 编排谱面。它从音符分布相似的人类谱面中取得一种风格，比如长条和多押的多少，再安排轨道、单点和长条。这一步还听不到音频。

最后得到的是一张在你浏览器里生成的完整 osu!mania 4K 谱面，可以对着音乐预览，也可以直接在 osu! 里打开。

R2 和行模型使用 osu! 上 2 到 6 星的 Ranked 与 Loved 4K 谱面训练。我们不分发这些谱面及其音频。

下一步：R3

我们正在开发下一代系统 R3。和 R2 一样，它涵盖时间轴、音符行（音符落在哪里）和配置（音符如何排列）。它按以下顺序解决 R2 暴露出的问题。

  1. 音符踩在音乐上

    音符应该落在你听到的声音上。我们正在让音符行更精确地对齐音频里实际的内容。

  2. 会听音乐的配置

    R2 的配置听不到音频。它根据音符的位置而不是声音来排列音符，这体现在不贴合音乐的长条上。在 R3 中，我们把音乐信息引入配置模型，让配置也能“听”。

  3. 减少隐藏的调控

    R2 在写谱时靠几条校准规则保持稳定，比如一股把谱面拉回既定风格的回复力。我们正在逐一检查，找出它们在哪些谱面上造成了变形。

  4. 可信的难度

    你要求多少星，谱面就应该是多少星。目前谱面可能比要求的更简单或更难。我们正在改进难度控制，要做好它，可能需要重塑系统的很大一部分。

这些是目标，工作仍在进行中。和 R2 一样，只有在确认之后，我们才会说明 R3 能做什么。

自己运行

上面的生成器通过 @ensomi/runtime 在浏览器中运行 R2：神经网络由 ONNX Runtime Web 运行，其余部分由编译成 WebAssembly 的 ensomi Rust 运行时完成。歌曲解码和随机数都在浏览器里进行，所以这里的种子和命令行中相同的种子不会得到相同的谱面。

从命令行运行正式版（已在 Apple 芯片的 macOS 上验证；Linux 和 CUDA 未运行过）：

git clone https://github.com/ensomi-labs/ensomi-model.git
cd ensomi-model
git checkout --detach r2-1.0.1
uv sync --python 3.10 --extra mps
hf download sed-i/ensomi-r2 --revision r2-1.0.1 --local-dir artifacts/hf-r2

uv run --python 3.10 --extra mps python -m ensomi_model.system.make \
  --model-dir artifacts/hf-r2 --audio /path/to/song.mp3 --star 3.5 \
  --title "Song title" --artist "Artist" --seed 0 --out artifacts/my-chart.osz

首次运行还会从作者处下载 BeatThis 的检查点（81 MB）。解码 WAV 以外的音频需要 ffmpeg。--help 会列出所有可用的请求。完整说明见 Hugging Face 模型卡（英文）。
